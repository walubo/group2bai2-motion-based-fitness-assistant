**How to add yourself:**

1. Create a branch named after you: `git checkout -b <your-github-username>`
2. Edit this file and replace `(add your role)` with your role (e.g., Frontend Developer, Backend Developer, UI/UX Designer, Tester, Documentation).
3. Commit with a clear message, e.g. `git commit -m "Add <Your Name> to MEMBERS.md as <Role>"`
4. Push your branch and open a pull request into `main`.
5. Wait for another member to review and merge your pull request.
